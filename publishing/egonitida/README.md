# egonitida

EgoNitida is a real-time 3D engine built on Effect, Three.js, and Foldkit. Designed as an agentic-first platform for individuals and teams alike, it works just as well without an agent. Use the `egonitida` command for quick access to official EgoNitida resources. Visit https://egonitida.com for more information.

```bash
npx egonitida
```
