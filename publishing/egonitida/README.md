# egonitida

EgoNitida is a real-time 3D engine built on Effect, Three.js, and Foldkit. The `egonitida` command serves as the official directory of EgoNitida, listing its current version, website, source code, packages, and social channels. Official EgoNitida packages are published exclusively under the @egonitida scope.

```bash
npx egonitida
```
