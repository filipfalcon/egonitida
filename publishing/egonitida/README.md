# egonitida

EgoNitida is a real-time 3D engine built on Effect, Three.js, and Foldkit. The `egonitida` command provides quick access to official EgoNitida resources. EgoNitida is designed for teams building interactive experiences on the web. It is developed with an emphasis on reliability, clarity, and long-term maintainability. For more information, visit egonitida.com.

```bash
npx egonitida
```
