# egonitida

EgoNitida is a real-time 3D engine built on Effect, Three.js, and Foldkit. Designed as an agentic-first platform for individuals and teams alike, it is equally at home in hands-on development. The `egonitida` command provides quick access to official EgoNitida resources. EgoNitida is developed with an emphasis on reliability, clarity, and long-term maintainability. For more information, visit egonitida.com.

```bash
npx egonitida
```
